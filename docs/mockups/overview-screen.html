모든 시안에 공통인 전제

아직 정해지지 않았고, 시안을 고른 뒤 확정할 항목입니다.

  • 화면 이름은 "종합"으로 두었습니다. 새 문자열이라 한국어 글꼴을 다시 만들어야 합니다.
  • 측정 화면 순환의 맨 앞에 넣는 것을 가정했습니다. 기존 순간·평균·누적·기록 화면은 그대로 둡니다.
  • 값이 네 자리를 넘거나 단위가 바뀌어도(mSv/h, cpm) 같은 자리에 들어가도록 오른쪽 정렬했습니다.
  • 경보 상태에서는 순간값과 채움 색이 경보색으로 바뀝니다. 기존 화면과 같은 규칙입니다.
  • 표본 숫자는 임의 값입니다.
